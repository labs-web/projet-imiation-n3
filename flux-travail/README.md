# Dossier du Flux de travail (`flux-travail/`)

Ce document explique à l'apprenant le rôle de ce dossier dans le projet et les éléments à y déposer.

---

## 1. Rôle du dossier

- Ce dossier documente l'ensemble des étapes de travail pour la réalisation du projet.
- Il permet de tracer précisément le déroulement du projet d'imitation (ou de tout projet technique ou fil rouge).
- Il sert de référence méthodologique pour comprendre l'enchaînement des étapes : de l'initialisation du projet jusqu'au déploiement.

---

## 2. Contenu attendu dans ce dossier

L'apprenant doit y placer :
- La description détaillée des étapes du flux de travail.
- Pour chaque étape : le travail réalisé, les entrées requises et les livrables attendus.
- Le suivi des méthodes appliquées (2TUP, Design Thinking, UML, Agile/Scrum).
