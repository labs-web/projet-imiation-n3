# Dossier de Gestion des Issues (`issues/`)

Ce document explique à l'apprenant le rôle de ce dossier dans le projet et les éléments à y déposer.

---

## 1. Rôle du dossier

- Ce dossier permet de tracer et planifier les tâches qui ne sont pas suivies directement par l'application LMS, ou les tâches supplémentaires demandées par le chef de projet ou proposées par l'apprenant.
- Les issues créées doivent être validées par le formateur avant d'être officiellement déposées sur le dépôt GitHub.

---

## 2. Contenu attendu dans ce dossier

L'apprenant y organise :
- `issues-open.md` : Les tâches et issues en cours de traitement.
- `issues-à-valider.md` : Les propositions d'issues en attente de validation par le formateur.
- `issues-closes.md` : Les tâches et issues terminées et archivées.
