# Tutoriel 1 : Prompt Engineering & Méthode RIO (`prompt-engineering/`)

Ce dossier contient l'ensemble des livrables du premier tutoriel de l'unité d'apprentissage UA.325.11.

---

## 1. Objectifs pédagogiques
- Comprendre la discipline du Prompt Engineering appliquée au génie logiciel.
- Maîtriser la méthode directrice **RIO** (Rôle, Instruction, Output).
- Connaître et appliquer les Prompt Engineering Patterns (Persona, Template, Constraint, Step-by-Step, Reflective).
- Savoir formuler des contraintes négatives et garde-fous stricts.
