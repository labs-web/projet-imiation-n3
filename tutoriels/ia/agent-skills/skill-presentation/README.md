# Tutoriel 3 (Atelier) : Conception du Skill `skill-presentation`

Ce dossier constitue l'atelier pratique d'expérimentation de la conception d'un skill modulaire pour l'unité d'apprentissage UA.325.11.

---

## 1. Objectifs de l'atelier
- Expérimenter la structure canonique d'un fichier `SKILL.md` ($\le 75$ lignes).
- Pratiquer le découpage modulaire avec une mission spécialisée dans `missions/`.
- Tester la découvrabilité native par frontmatter YAML.

---

## 2. Livrables de l'atelier
- [skill-presentation.md](./skill-presentation.md) : Fiche de compte-rendu technique de l'atelier de conception.
- [presentation-skill-presentation.md](./presentation-skill-presentation.md) : Diaporama Marp pour la soutenance orale de l'atelier.
- [SKILL.md](./SKILL.md) : Fichier de compétence orchestrateur prêt à l'emploi.
- [missions/marp-slides.md](./missions/marp-slides.md) : Mission spécialisée dans la création de diapositives Marp.
