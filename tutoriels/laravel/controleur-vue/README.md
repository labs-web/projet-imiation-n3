# Unité d'Apprentissage : Démarrage rapide Laravel — Contrôleur et Vue (`controleur-vue/`)

Cette unité met en œuvre le pattern MVC en isolant l'orchestration HTTP dans un contrôleur dédié (`ArticleController`) pour extraire et afficher dynamiquement une collection d'articles via les directives de boucle Blade.
