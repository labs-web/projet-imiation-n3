---

## 2. Description de l'Unité d'Apprentissage
Cette unité d'apprentissage guide l'apprenant dans la découverte de l'Agilité et l'application opérationnelle du cadre Scrum.
Elle se compose de **5 tutoriels modulaires** où chaque étape permet d'acquérir les notions fondamentales de Scrum et de les mettre immédiatement en application sur son **projet technique individuel : Création et gestion d'un portfolio**.

---

## 3. Inventaire et Index des 5 Livrables de Tutoriels

Les 5 dossiers de tutoriels ci-dessous constituent les livrables effectifs créés pour cette unité d'apprentissage :

- **[Tutoriel 1 : comprendre-scrum/](./comprendre-scrum/)**
  - *Titre* : Comprendre l'approche Agile et le cadre Scrum
  - *Fiche technique* : [comprendre-scrum.md](./comprendre-scrum/comprendre-scrum.md)
  - *Diaporama Marp* : [presentation-comprendre-scrum.md](./comprendre-scrum/presentation-comprendre-scrum.md)
  - *Application Portfolio* : Définir sa posture de développeur et fixer la cadence de sprint (1 semaine).

- **[Tutoriel 2 : vision-besoins/](./vision-besoins/)**
  - *Titre* : Définir la vision produit et exprimer les besoins en User Stories
  - *Fiche technique* : [vision-besoins.md](./vision-besoins/vision-besoins.md)
  - *Diaporama Marp* : [presentation-vision-besoins.md](./vision-besoins/presentation-vision-besoins.md)
  - *Application Portfolio* : Rédiger la vision produit et les 5 User Stories majeures avec critères d'acceptation.

- **[Tutoriel 3 : product-backlog/](./product-backlog/)**
  - *Titre* : Créer, estimer et ordonner le Product Backlog
  - *Fiche technique* : [product-backlog.md](./product-backlog/product-backlog.md)
  - *Diaporama Marp* : [presentation-product-backlog.md](./product-backlog/presentation-product-backlog.md)
  - *Application Portfolio* : Construire le backlog ordonné, estimer l'effort, appliquer MoSCoW et fixer la DoD.

- **[Tutoriel 4 : sprint-planning-execution/](./sprint-planning-execution/)**
  - *Titre* : Planifier, découper et piloter un Sprint de développement
  - *Fiche technique* : [sprint-planning-execution.md](./sprint-planning-execution/sprint-planning-execution.md)
  - *Diaporama Marp* : [presentation-sprint-planning-execution.md](./sprint-planning-execution/presentation-sprint-planning-execution.md)
  - *Application Portfolio* : Fixer le Sprint Goal du Sprint 1, décomposer les stories en tâches de code et animer le tableau Kanban.

- **[Tutoriel 5 : revue-retrospective/](./revue-retrospective/)**
  - *Titre* : Valider l'incrément, animer la Sprint Review et la Rétrospective
  - *Fiche technique* : [revue-retrospective.md](./revue-retrospective/revue-retrospective.md)
  - *Diaporama Marp* : [presentation-revue-retrospective.md](./revue-retrospective/presentation-revue-retrospective.md)
  - *Application Portfolio* : Démontrer l'incrément du portfolio, collecter les feedbacks et définir 3 améliorations pour le Sprint 2.
