# Initialisation README (`1.init-projet.prompt.md`)

Nettoyer et structurer le fichier `README.md` racine à partir d'un texte brut.

## Entrée
Texte brut ou brouillon du projet (description, objectifs, technologies).

## Structure attendue du `README.md`
- `# [Nom du Projet]`
- `## 1. Description du projet` (résumé en 2-3 phrases, utilisateurs cibles, déploiement)
- `## 2. Contexte et Objectifs` (contexte, objectifs techniques ; inclure *objectifs pédagogiques* uniquement si cadre de formation)
- `## 3. Stack technique` (frontend, backend, base de données, Git)
- `## 4. Organisation des dossiers` (rôle des dossiers : `docs/`, `flux-travail/`, `prompts/`, `issues/`, `src/`)
- `## 5. Méthodologie` (Agile/Scrum, 2TUP, Design Thinking)
- `## 6. Démarrage rapide` (prérequis, cloner, lancer)

## Règles
- Respecter le niveau de français A1 et le vocabulaire technique de développeur.
- Aucun tableau Markdown (utiliser exclusivement des listes à puces).
- Liens relatifs uniquement.
- Générer uniquement le contenu Markdown du `README.md`.
