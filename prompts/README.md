# Prompts du projet

Ce dossier regroupe les règles de rédaction et les prompts standardisés du projet.

## Règles générales de rédaction

- Fichier de référence : [regles-redaction.md](file:///d:/labs-web/projet-imiation-n3/prompts/regles-redaction.md)
  - Niveau de français A1 (phrases courtes et simples).
  - Vocabulaire technique professionnel obligatoire.
  - Interdiction des tableaux Markdown (utiliser des listes à puces pour faciliter les modifications par l'apprenant).

## Liste des prompts

- **Prompt initial des règles** : [init.prompt.md](file:///d:/labs-web/projet-imiation-n3/prompts/init.prompt.md)
  - Rôle : Initialiser l'IA avec les 3 règles obligatoires (Français A1, vocabulaire technique, pas de tableaux).
  - Utilisation : À envoyer à l'IA au début de chaque session.

- **Prompt étape 1 (`init-projet`)** : [1.init-projet.prompt.md](file:///d:/labs-web/projet-imiation-n3/prompts/1.init-projet.prompt.md)
  - Rôle : Nettoyer et structurer le fichier `README.md` à partir d'un brouillon brut.
  - Livrable généré : `README.md`.
