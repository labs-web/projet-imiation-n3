# Initialisation du Projet (`1.init-projet.mission.md`)

Initialiser le projet en local, le publier sur GitHub et structurer son fichier `README.md`.

## Tâches de la mission
- **Tâche 1 : Initialisation locale** : Vérifier ou exécuter l'initialisation Git locale (`git init`) et le commit initial.
- **Tâche 2 : Publication sur GitHub** :
  - Publier le dépôt via GitHub CLI avec la commande : `gh repo create`.
  - Si GitHub CLI (`gh`) n'est pas installé ou non connecté : indiquer à l'apprenant qu'il doit réaliser le lab : `lab-github : installation et utilisation de github CLI`.
- **Tâche 3 : Rédaction du README.md** : Reformuler et structurer le fichier `README.md` racine selon la structure du livrable ci-dessous en intégrant la stack technique du projet (Laravel).

## Livrables attendus
- Dépôt GitHub distant créé et synchronisé.
- Fichier `README.md` racine propre et conforme.

## Protocole d'audit et exécution
- **Si l'apprenant précise une tâche** : Exécuter directement la tâche demandée sans créer d'artefact plan.
- **Si aucune tâche n'est précisée** : Auditer l'état des livrables (Git local, publication GitHub, contenu du `README.md`) et proposer les actions à réaliser dans un artefact plan pour validation de l'apprenant.

## Structure du livrable (README.md)
- `# [Nom du Projet]`
- `## 1. Description du projet` (résumé en 2-3 phrases, utilisateurs cibles, déploiement)
- `## 2. Contexte et Objectifs` (contexte Solicode Tanger, formateur, objectifs techniques et pédagogiques)
- `## 3. Stack technique` (framework backend Laravel, frontend, base de données, Git)
- `## 4. Organisation des dossiers` (rôle des dossiers : `.agents/`, `docs/`, `flux-travail/`, `issues/`, `labs/`, `missions/`, `sprints/`)
- `## 5. Méthodologie` (Agile/Scrum, 2TUP, Design Thinking, modélisation UML)
- `## 6. Démarrage rapide` (prérequis, cloner, lancer)

## Règles
- Français A1 et vocabulaire technique professionnel de développeur.
- Aucun tableau Markdown (utiliser exclusivement des listes à puces `- `).
- Liens relatifs uniquement.
